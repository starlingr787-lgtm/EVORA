# EVORA Studio

A static marketing site for EVORA Studio, built with HTML, CSS, and JavaScript.

## Project files

- `index.html` — page markup, styling, interactions, and contact form.
- `assets/images/` — site photography and visual assets.

## Live site

[Open EVORA Studio](https://evora-publish-g3h9efmoa-evora14.vercel.app/)

The Vercel project is connected to this repository's `main` branch and deploys new commits automatically. No build step is required.
